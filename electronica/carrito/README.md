# Carrito

Proyecto de placa de circuito impreso (PCB) en KiCad para el carrito.

## Estructura

| Carpeta | Contenido |
|---|---|
| `kicad/` | Proyecto de KiCad: esquemático, PCB y archivo de proyecto |
| `fabricacion/` | Archivos para fabricación: Gerbers y drills, lista de materiales (BOM), posiciones, designadores y netlist |
| `fabricacion/gerber/` | Archivos Gerber (capas de cobre, máscara, serigrafía, pasta y contorno) y archivos de taladro |

Los respaldos automáticos de KiCad, el historial local y los archivos de bloqueo no se incluyen.
